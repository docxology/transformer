# Examples

Run these modules from the repository root inside the environment in the
[quick start](../docs/guides/quickstart.md).

| Command | Demonstration |
| --- | --- |
| `python -m examples.basic_usage` | Capture a forward pass and visualize attention and residuals |
| `python -m examples.path_analysis` | Count and enumerate paths in the teaching grid |
| `python -m examples.animation_demo` | Animate information flow and attention |
| `python -m examples.training_example` | Train a small model on synthetic token sequences |
| `python -m examples.manuscript_probe --output-dir output` | Reproduce the manuscript's CPU experiment |

See [running and configuration](../docs/guides/running.md) for output locations
and [visualization](../docs/guides/visualization.md) for headless operation.
