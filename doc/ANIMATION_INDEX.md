## Animation Details

### 1. Information Flow

**File**: `01_information_flow.gif`

**Shows**: The complete dual-highway information architecture
- Residual stream (vertical flow through layers)
- K/V stream (horizontal flow across positions)
- Combined path visualization

**When to use**:
- Explaining transformer architecture to others
- Understanding overall information movement
- Identifying computational bottlenecks

**Generated by**:

## Generation Scripts

### Generate All Animations

Use the comprehensive generator:

```bash
python generate_all_animations.py
```

**Outputs**:
- All 9+ animations in `outputs/animations/`
- Structured logging in `outputs/logs/`
- Performance metrics in JSON format

### Generate Specific Animations

```python
import sys
sys.path.insert(0, '.')

import torch
from src.transformer import Transformer, TransformerConfig
from src.visualization import *
from src.visualization.advanced_animations import *

# Setup
config = TransformerConfig(d_model=256, n_heads=8, n_layers=4)
model = Transformer(config)
input_ids = torch.randint(0, config.vocab_size, (1, 12))

with torch.no_grad():
    logits, state = model(input_ids, return_state=True)

# Generate desired animations
animate_attention_evolution(state, save_path='custom_attn.gif')
animate_token_interactions(state, save_path='custom_tokens.gif')
```

## Customization Options

### Speed Control

```python

animate_*(..., fps=3)

animate_*(..., fps=5)
```

### Quality vs Size

**Higher quality** (larger file):
- More frames (higher fps)
- Larger figures
- More layers/positions

**Smaller files** (faster loading):
- Fewer frames (lower fps)
- Smaller models
- Shorter sequences

## Integration with Logging

All animations can be logged:

```python
from src.utils.logging_system import TransformerLogger

logger = TransformerLogger("animation_session")

animations = [
    ('info_flow', animate_information_flow),
    ('attention', animate_attention_evolution),
    # ...
]

for i, (name, func) in enumerate(animations):
    logger.info(f"[{i+1}/{len(animations)}] Generating {name}...")
    func(state, save_path=f'outputs/animations/{name}.gif')
    logger.log_metric(f"{name}_created", 1.0, step=i)

logger.save_metrics()
```

## Troubleshooting

### Animation too slow
- Reduce `fps`
- Use smaller model (`get_preset_config('tiny')`)
- Shorter sequence length

### Out of memory
- Reduce sequence length
- Use smaller `d_model`
- Generate one animation at a time

### Poor quality
- Increase figure size in source
- Use higher `fps`
- Increase DPI (requires code modification)
